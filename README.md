# DJ Anthem Mapper

Native macOS SwiftUI baseline for Ian's private DJ Anthem Mapper project.

Target development machine:
- MacBook Pro Mac14,5
- Apple M2 Max / arm64
- 32 GB RAM
- macOS Ventura 13.7.8 (22H730)
- Xcode 15.2

Compatibility rule: macOS 13 / Xcode 15.2 baseline. Do not introduce APIs or language features that require a newer toolchain without explicitly changing the baseline.

Hookfinder integration is intentionally separated from this initial shell. Permission for private, non-commercial use was supplied by the user; preserve an acknowledgement when integration is added.
